# GPT Multi-Body Protocol v1.1

## Architecture

GPT is the decision layer. Each physical Codex is a Body. A task requirement is resolved by responsibility, data ownership, OS, hardware, environment, and permissions before load is considered (`AFFINITY_BEFORE_LOAD`). Agent load and local compute load are independent dimensions.

The execution path is:

`Task Requirement → Persistent Registry/DAG → Affinity Selector → Agent Scheduler → Single-Owner Gate → Codex Body → Compute Router → Receipt → Automatic Callback → GPT ACK`

The Registry preserves stable business task identity, execution generation, dependency lifecycle, assigned Body, Receipt, Callback, and ACK state. The Single-Owner Gate must claim before any Codex subprocess and rejects duplicate or noncanonical callers.

## Compute policy

MacBook Pro does not register local AI Compute. Model requests from MacBook Codex route to Office-4090 over the configured 11434 inference endpoint. Office-4090 Codex uses its local RTX 4090 Compute by default. Mac Studio remains RESERVED and is modeled for future Agent plus Local Compute registration. Port 11435 is model scheduling control and is not a device-access prerequisite.

## Compatibility and generation rollover

The legacy Desktop execution session is retained permanently as `LEGACY_COMPATIBILITY_BLOCKED`. Runtime compatibility failure requires explicit GPT approval before creating exactly one successor generation. The successor records its predecessor, reason, creation time, and status. Exact resume requires the same returned session/thread ID, append-only rollout growth, historical prefix integrity, and no fork or additional session.

Runtime discovery prefers the ChatGPT bundled executable and compares its version with the rollout writer version. Older PATH runtimes fail closed. The current legacy limitation is a Codex Desktop interoperability issue: CLI resume can read/write a Desktop-origin session differently from Desktop UI/index refresh behavior. This does not change Controller execution identity guarantees.

## Release notes

v1.1 adds persistent scheduling, affinity-first Body selection, independent Agent/Compute load, real MacBook/Office-4090 routing, deterministic failure recovery, Single-Owner enforcement, successor generation lineage, and integrated low-resource validation. Mac Studio and heavy inference remain outside the release scope.
